# The Test Library · 收款材料准备指南

> 建立日期：2026-11-25
> 用途：AdSense 审核通过后能立刻收款，不因税务表、付款方式卡住第一笔钱
> 适用：中国大陆个人身份 · Payoneer 收款

---

## 一、整体链路（先看清全貌）

```
AdSense 收入
  → Google 结算（按 W-8BEN 决定预扣税）
  → Payoneer 提供的美国本地银行账号
  → Payoneer 余额
  → 提现到国内银行卡（人民币）
```

要办的就是两件事：**W-8BEN 税务表** 和 **Payoneer 美国银行账号**。两件互相独立，可以同时开始。

---

## 二、W-8BEN 税务表

### 它是什么

非美国居民声明表。Google 是美国公司，付钱给非美国创作者时，美国税法要求先确认税务身份。

**不需要下载 PDF 上传**——AdSense 后台是一问一答的表单，Google 根据你的回答自动生成对应 IRS 表格。

### 不填的代价（关键）

| 税务信息状态 | 预扣多少 | 扣哪部分 |
| --- | --- | --- |
| 完全不填 | 24% | 全球收入的**全部** |
| 填了 W-8BEN，但没主张税收协定 | 30% | 仅美国访客产生的收入 |
| 填了 W-8BEN + 有效税收协定 | 按协定税率（中国通常 10%） | 仅美国访客产生的收入 |

中国大陆与美国有税收协定，AdSense 收入通常归入"其他版权使用费"类别，协定税率一般为 **10%**。所以正确填表能把预扣税从 24% 降到 10% 以下。**具体税率以 AdSense 后台生成的表为准**，本指南不构成税务建议。

### 找不到「美国税务信息」怎么办（账号阶段问题）

中文界面的对应名称是 **美国税务信息**（不是英文 United States tax info）。但**如果账号还在初始设置阶段，这一栏根本不会出现**——这是正常现象，不是你找错地方。

判断账号阶段的信号（首页"让我们协助您开始"那屏）：

- 「将您的网站关联到 AdSense」卡片还标着 **必需** → 网站尚未关联，账号未完成 onboarding
- 「收款」卡片显示"我们已获得您的信息" → 只说明基本收款资料已填，**不代表税务信息已开放**

税务信息表单通常要等**网站关联 + 账号审核通过**后才会出现。所以现在的正确顺序是：

1. 先点首页「我们开始吧」或「添加网站」，把 `thetestlibrary.app` 关联进 AdSense
2. 提交审核，等待通过（通常几天到几周）
3. 审核通过后，再按下面的路径填税务信息

> 官方要求：税务信息需在**当月 20 日前**提交，才能在当月收到付款。所以账号一通过就填，别拖到有收入再补。

### 填写步骤

1. 登录 AdSense → 左侧菜单 **收款 → 收款信息**（英文界面：Payments → Payments info）→ 点 **管理设置**（Manage settings）
2. 向下滚动到 **收款资料**（Payments profile）区块，找到 **美国税务信息**（United States tax info），点旁边的修改图标 → **管理税务信息**（Manage tax info）
3. 选择账户类型：
   - 以个人身份运营 → **Individual** → 拿到的是 **W-8BEN**
   - 有公司主体 → **Business** → 拿到的是 **W-8BEN-E**
   - 本站是个人站，选 **Individual**，别选错
4. 是否在美国有经营活动（US activities）：**No**（人在中国、没有美国雇员或设备）
5. 税务居民国：**China**
6. 外国税号（TIN）：填**中国大陆身份证号码**
7. 主张税收协定优惠：**勾选**，国家选 China，收入类型/协定条款让系统自动带出
8. 预览 Google 生成的 PDF，确认无误后电子签名提交
9. 状态变成绿色的 **Approved** 即完成，旁边会显示适用税率

### 常见坑

- **名字拼音必须与身份证 / 护照完全一致**，不然身份核验会卡住
- 非 9 位的中国税号会触发额外的身份验证，这是正常流程，按提示做即可
- W-8BEN 有效期 **3 年**，到期前 Google 会邮件提醒续签
- 如果误提交了 W-8BEN-E，去税务设置页删掉旧表重新提交，多数平台支持即时修改

### 中国大陆账户还要填新加坡税务信息

中国大陆和香港的 AdSense 账户，广告收入实际由 **Google 新加坡**支付。因此同一个税务模块里可能还会有**新加坡税务声明**要填：

- 在同一税务信息页面，看是否有 Singapore tax info / 新加坡税务信息 的条目
- 选择 **非新加坡税务居民**，按向导完成声明
- 这一步不填，可能导致更高比例预扣

> 是否出现这一项取决于你账号的收款主体归属，以 AdSense 后台实际显示为准。后台显示了就填，没显示不用管。

## 三、Payoneer 美国银行账号

### 为什么用 Payoneer

AdSense 支持银行电汇，但从中国直接收美元电汇会被国内银行收入账费、也可能有额度麻烦。Payoneer 提供一个**美国本地银行账号**，AdSense 把它当美国银行账户打款，到账更快、费用更低。

### 注册与绑定步骤

1. 打开 **payoneer.com** 注册账号，主体类型选**个人 / 自由职业者**
2. 填真实身份信息，上传**身份证正反面**扫描件，等审核（通常 1–3 个工作日）
3. 审核通过后，进入 **收款（Receive）** 板块，获取**美国本地银行账号**（美元 ACH 收款账户）
4. 记下三个字段：**Bank Name / Account Number / Routing Number**
5. 回到 AdSense → **付款 → 付款方式 → 添加付款方式**，选银行电汇，填入上面的账号信息
6. **姓名必须与 Payoneer 实名、身份证完全一致**，这是绑定失败的最常见原因
7. 等一笔小额验证（$0.01–$0.99）：去 Payoneer 的**交易记录**里看到实际入账金额，回 AdSense 填入准确数字
8. 绑定完成

### 常见坑

- W-8BEN 未生效、两边实名不一致、注册邮箱不一致 → 绑定失败；按顺序检查这三项
- 小额验证金额**要看 Payoneer 交易记录**，不要猜
- AdSense 显示"已付款"但 Payoneer 没收到，通常银行清算延迟 2–3 天；48 小时后再联系支持，并附上 AdSense 付款截图

## 四、AdSense 付款节奏（预期管理）

| 项目 | 说明 |
| --- | --- |
| 付款门槛 | **$100**，余额不到就累积到下个月 |
| 结算时间 | 每月收益累加，次月约 **21 日**结算上月金额 |
| 到 Payoneer | 付款后约 3–7 个工作日 |
| 提现到国内卡 | Payoneer 人民币提现费率约 0.5%–1.5%（看累计交易量），外汇转换约中间价 +1.2% |
| 省钱技巧 | 单笔提现尽量 > $300，摊薄固定成本；别余额长期低于 $10（可能有休眠费） |
